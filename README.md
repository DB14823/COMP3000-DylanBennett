# Omnimonitor

**COMP3000 Computing Project — University of Plymouth, 2026–27**
**Author:** Dylan Bennett
**Supervisor:** _TBC (to be confirmed by 12 October 2026)_

## Vision

An iOS closed-loop insulin delivery app for people with type 1 diabetes that lets the user photograph a meal, estimates its carbohydrate content using the iPhone's LiDAR sensor and on-device machine learning, and turns that estimate into a reviewed, safety-checked insulin dose.

> ⚠️ Research project. This software is not a medical device and is not approved for clinical use.
